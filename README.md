Auto Stock - Sistema de Gerenciamento de Estoque
📌 Sobre o Projeto

O Auto Stock é um sistema web desenvolvido para auxiliar no gerenciamento de estoque de forma prática e eficiente. A aplicação permite o controle de peças e produtos cadastrados, facilitando a organização, consulta e atualização das informações do estoque.

O projeto foi desenvolvido como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas.

🚀 Funcionalidades
Cadastro de produtos/peças
Edição e exclusão de itens
Controle de quantidade em estoque
Sistema de autenticação de usuários
Consulta rápida de produtos
Interface web intuitiva
Controle de entrada e saída de itens

O objetivo do Auto Stock é fornecer uma solução simples e funcional para controle de estoque, permitindo maior organização e eficiência no gerenciamento de materiais e produtos.
